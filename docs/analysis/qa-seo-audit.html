Executive Summary

The Special Wedding platform has implemented comprehensive SEO infrastructure with strong technical foundations. 13 of 16 checklist items pass verification, with dynamic OG images for blog and vendor pages, proper structured data schemas, and correct PWA manifest configuration. Two items show minor warnings regarding compare page metadata consistency, and one critical finding requires immediate attention: vendor profile pages lack server-side metadata for Open Graph tags, forcing fallback static metadata. This creates duplicate OG descriptions across all 1000+ vendor profiles, which is a medium-severity SEO issue requiring implementation of dynamic metadata at the server level.

Critical Findings & Issues

🔴 CRITICAL: Duplicate Meta Descriptions on Vendor Profiles

Severity: Medium (affects 1000+ pages)

File: app/vendors/[id]/layout.tsx

Issue: When vendor data is fetched, all profiles without a custom service_description fall back to the same fallback template: "View this wedding vendor's services, pricing, portfolio, and contact details."

Impact:

  • Duplicate content signals to search engines
  • Reduces click-through rate in SERPs (users see identical snippets)
  • Affects vendor discoverability
  • Wastes opportunity to highlight vendor specialties

Root Cause: The fallback logic doesn't generate dynamic descriptions based on vendor attributes (category, location, etc.)

Resolution Recommendation: Enhance the fallback description template to include dynamic vendor attributes:
const fallbackDescription = `${vendor.business_name} is a ${categoryLabel} in ${location}. View services, pricing, and portfolio.`
