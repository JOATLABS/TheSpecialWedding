📋 Mockup Design Notes

  • Sidebar placement: "Vendor Scraper" sits between Ad Platform and Notifications (root admin only)
  • Stats cards: Live counters that update via SSE as the scraper runs
  • City selector: Toggle buttons — pink = selected, gray = deselected. "Select all" / "Clear all" toggle
  • Category filter: All-on toggle or pick specific ones when toggled off
  • Dry Run toggle: When ON, shows yellow "NO DB WRITES" badge and scraper logs show "[DRY RUN]" prefix
  • Live Output: Terminal-style panel with color coding — green ✓ for inserts, yellow ⚠ for skips, red ✗ for errors
  • Run History: Click any row to expand and show the log tail from that run. Persisted to scraper_runs MongoDB collection
  • SSE streaming: Reuses your existing SSEProvider pattern — logs push in real time, no polling
  • Only one run at a time: Starting a second run while one is active returns 409 Conflict
  • Stop button: Replaces "Run Scraper" while active — disconnects SSE and cancels the background task
