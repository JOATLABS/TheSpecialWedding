Dashboard — Updates Tab

/couple/dashboard → Updates

A feed combining planner-posted updates and auto-generated milestone cards. The planner posts updates from their dashboard — text, categories, and attachments. Milestones get a gold/rose gradient header. No presentation-building needed — the data is already nicely designed here.
