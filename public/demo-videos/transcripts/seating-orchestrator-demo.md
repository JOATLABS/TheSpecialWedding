# Seating Chart Orchestrator

Audience: Planners who need floor-plan-aware seating, not only table lists.
Target duration: 60 seconds

## Script

### 0:00-0:12

Action: Open Seating, use the in-product Zoom out control twice to reach 70%, and show the room outline with fixtures.

This is the seating chart, built on the actual room — the venue outline, its fixtures, and tables placed where they will really stand.

### 0:12-0:36

Action: Inspect the populated tables and existing guest assignments without moving anyone.

The tables are already populated, and every seated guest arrives with their record attached — meal context and household notes stay connected while the planner places people, so seating decisions run on information instead of memory.

### 0:36-1:00

Action: Inspect assigned totals, floor-plan status, and the visible layout checks.

Beside the canvas, the chart reports its own readiness: assigned totals, floor-plan status, and the visible layout checks. What starts as a diagram becomes an export-ready day-of artifact with the venue context intact.
