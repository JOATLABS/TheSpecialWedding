# Planner command center walkthrough

Audience: Professional planners who want to see one wedding record stay coherent across planner, public, couple, and guest-response views.
Target duration: 75 seconds

## Script

### 0:00-0:10

Action: Scan the planner portfolio and choose Manage for Sofia & Daniel.

Start with one wedding in the planner command center, then follow its plan instead of touring disconnected tools.

### 0:10-0:30

Action: Open Events and inspect the Glasshouse venue and 4:00 PM start time.

The wedding record is the source of truth. Open Events and the Traditional ceremony is already specific: The Glasshouse at Riverbend, a four o’clock start — captured once, in the one plan the entire wedding runs on.

### 0:30-0:40

Action: Manually switch to the public tab and inspect the matching event details.

The guest-facing microsite shows that same venue and the same four o’clock, presented cleanly with no planner controls.

### 0:40-0:50

Action: Manually switch to the couple tab, open Timeline, and inspect the matching plan.

The couple’s guided portal carries the identical plan — same venue, same time — while planner-only operations stay private.

### 0:50-1:05

Action: Return to the planner, open Guests, and filter the table to Declined.

Back in the planner workspace, one filter isolates every declined guest with group and plus-one context intact — the operational picture, without reconciling another spreadsheet.

### 1:05-1:15

Action: Return to the command center, then hold for the five-second outro.

One planner-owned workspace. Start with one wedding.
