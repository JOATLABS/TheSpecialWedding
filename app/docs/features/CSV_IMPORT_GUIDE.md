# Guest Import CSV Format Guide

## Required Columns

### 1. **name** (REQUIRED)
- **Description**: Guest's full name
- **Format**: Text string, minimum 2 characters
- **Example**: "John Smith", "Jane Doe"

### 2. **phone** OR **email** (At least ONE required)
- **Description**: Contact information for sending reminders and communications
- **Format**: 
  - Phone: 10-15 digits only (no spaces, dashes, or country codes)
  - Email: Valid email address format
- **Example**: 
  - Phone: "1234567890"
  - Email: "john@example.com"

## Optional Columns

### 3. **phone**
- **Description**: Guest's phone number for SMS reminders
- **Format**: 10-15 digits only (no formatting)
- **Default**: None (empty)
- **Example**: "1234567890"

### 4. **email**
- **Description**: Guest's email address
- **Format**: Valid email format
- **Default**: None (empty)
- **Example**: "john@example.com"

### 5. **role**
- **Description**: Guest's role or category
- **Format**: Text string
- **Valid Values**: "guest", "vip", "vendor", "admin", "family", "friend", etc.
- **Default**: "guest"
- **Example**: "vip", "family"

### 6. **plus_one_allowed**
- **Description**: Whether this guest is allowed to bring plus-ones
- **Format**: Boolean text
- **Valid Values**: "true" or "false" (case-insensitive)
- **Default**: "false"
- **Example**: "true"

### 7. **number_of_plus_ones_allowed**
- **Description**: Maximum number of plus-ones this guest can bring
- **Format**: Integer between 0 and 10
- **Default**: 0
- **Example**: "2", "1", "3"
- **Note**: Automatically set to 0 if plus_one_allowed is false

### 8. **group_id**
- **Description**: Identifier for grouping related guests (families, tables, etc.)
- **Format**: Text string (alphanumeric recommended)
- **Default**: None (empty)
- **Example**: "grp_fam_001", "table_5", "college_friends"

## Sample CSV File

```csv
name,phone,email,role,plus_one_allowed,number_of_plus_ones_allowed,group_id
John Smith,1234567890,john@email.com,guest,true,2,grp_fam_001
Jane Doe,9876543210,jane@email.com,guest,true,1,grp_fam_001
```

## Important Notes

1. **Contact Information**: Every guest must have at least a phone number OR email address for communication
2. **Phone Format**: Enter phone numbers without any formatting (no spaces, dashes, or parentheses)
3. **Plus-One Logic**: If plus_one_allowed is "false", number_of_plus_ones_allowed will be set to 0 regardless of the value in CSV
4. **Group IDs**: Use consistent group_id values to keep related guests together
5. **Case Sensitivity**: The role and boolean fields are not case-sensitive

## Fields Auto-Generated by System

The following fields are automatically created and should NOT be included in your CSV:
- `token` - Unique invitation code
- `wedding_id` - Selected through the admin interface
- `created_at` - Timestamp when guest is imported
- `updated_at` - Timestamp of last update
- `plus_one_submitted` - Tracks if all plus-one slots have been filled
- `checked_in` - Tracks event check-in status

## Validation Rules

- Rows without a name (or with names less than 2 characters) will be skipped
- Rows without either phone or email will be skipped
- Invalid phone numbers or email addresses will cause the row to be skipped
- The import will continue even if some rows fail validation
